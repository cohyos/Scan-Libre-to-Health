# Libre → Health

אפליקציית ווב לייבוא נתוני סוכר מ-FreeStyle LibreView לאפליקציית הבריאות של אפל (Apple Health).

## תכונות

- **ייצוא מ-LibreView** — קישור ישיר לאתר LibreView לייצוא דוח נתוני סוכר ל-18 חודשים
- **קריאת CSV** — זיהוי אוטומטי של מבנה הקובץ, תמיכה בכותרות בעברית ובאנגלית
- **סינון לפי תאריכים** — בחירת טווח תאריכים להצגת נתונים רלוונטיים בלבד
- **מיזוג עמודות סוכר** — העתקת ערכי סריקה לעמודת סוכר היסטורי כשהעמודה ריקה
- **מיון כרונולוגי** — סידור הנתונים מהמוקדם למאוחר
- **סטטיסטיקות** — ממוצע, מינימום, מקסימום וצביעת ערכים לפי טווח
- **הורדת קובץ מעובד** — ייצוא ה-CSV המסונן והממוין
- **ייבוא ל-Apple Health** — העתקת נתונים ללוח והפעלת קיצור דרך (Shortcut) באייפון

## שימוש

1. פתחו את `index.html` בדפדפן באייפון (או באמצעות GitHub Pages)
2. לחצו על הקישור לפתיחת LibreView וייצאו את הנתונים כ-CSV
3. העלו את קובץ ה-CSV לאפליקציה
4. בחרו טווח תאריכים ולחצו "עיבוד הנתונים"
5. הורידו את הקובץ המעובד או העתיקו ל-Apple Health

## מבנה הקובץ הנתמך

הקובץ המיוצא מ-LibreView בפורמט CSV עם העמודות:

| # | עמודה | תיאור |
|---|--------|--------|
| 1 | מכשיר | שם המכשיר (FreeStyle LibreLink) |
| 2 | מספר סידורי | מזהה הסנסור |
| 3 | חותמת זמן מכשיר | תאריך ושעה (DD-MM-YYYY HH:MM) |
| 4 | סוג רשומה | 0=היסטורי, 1=סריקה |
| 5 | רמות סוכר היסטוריות | קריאה אוטומטית כל 15 דקות |
| 6 | רמת סוכר מסריקה | קריאה ידנית בסריקת הסנסור |

## PWA

ניתן להוסיף את האפליקציה למסך הבית של האייפון:
1. פתחו את הדף ב-Safari
2. לחצו על כפתור השיתוף
3. בחרו "הוסף למסך הבית"

## טכנולוגיה

HTML + CSS + JavaScript בלבד, ללא תלויות חיצוניות. כל העיבוד מתבצע בדפדפן — אין שרת, הנתונים לא נשלחים לשום מקום.
